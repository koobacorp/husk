# Test audio

"Ble Rei Di? Traditional Welsh song", sung unaccompanied by Robin Owain and uploaded to Wikimedia
Commons by Llywelyn2000:
https://commons.wikimedia.org/wiki/File:Ble_Rei_Di%3F_Traditional_Welsh_song.wav

resampled and level-normalised; it is used only as test material. This file (and only this file)
is distributed under CC BY-SA 4.0.

The synthetic sung phrase and vowel sequence used by `husk_quality_tests` are generated in code.
